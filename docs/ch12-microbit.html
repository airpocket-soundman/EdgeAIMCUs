第12章

micro:bit（nRF52833）

学校でもおなじみの小さなボード。実はAIのしくみを「手で」確かめるのに、うってつけなんです。

ボード紹介

micro:bit（マイクロビット）は、イギリスで子どもたちのプログラミング教育のために生まれたボードです。日本でも多くの学校で使われています。いまの主流は micro:bit V2 で、心臓部は Nordic の nRF52833。

micro:bit V2（参考）micro:bit V1
チップNordic nRF52833Nordic nRF51822
コアCortex-M4F、64MHzCortex-M0、16MHz
RAM128KB16KB
Flash512KB256KB
ボードに載っているもの5×5 のLED、ボタン2つ、加速度・地磁気センサー、Bluetooth。V2 はさらにマイクとスピーカー、タッチセンサー
開発環境MakeCode（ブロック）、MicroPython、C/C++（CODAL）

V2 には、マイクと加速度センサーがはじめから載っているのが大きなポイント。配線なしで「音」と「動き」のAIをすぐに試せます。

ヒント

micro:bit 公式の micro:bit CreateAI を使うと、ブラウザの上で、micro:bit を振って動きのデータを集めて、学習させて、MakeCode のプログラムに組み込むまでができます。「最初の1個」をいちばん手軽に動かせる道具のひとつです。

実例：背中に書いた数字を当てる（おとうさんの背中）

子どものころ、お父さんの背中に指で字を書いて「なんて書いたでしょう？」と当てっこしませんでしたか？ おとうさんの背中 は、その遊びをAIでやってみようという作品です。

いまは試作の段階で、背中のかわりに 16×18 マスの小さなタッチパネルを作り、そこに指で書いた数字（0〜9）を micro:bit V2 が当てます。

しくみ

  1. タッチパネルの 16×18 = 288マスのどこが触られたかを読み取る。
  2. 触った線を太らせて（中心を255、上下左右を150に）、手書き数字の画像のようにする。
  3. 288個の数値を、288 → 64 → 10 の小さな全結合ネットワーク（MLP）に入れる。
  4. 10個の出力のうち、いちばん大きいものが答えの数字。

自分で書いた int8 推論エンジン

この作品のモデルは、TensorFlow Lite などのライブラリを使わず、推論のプログラムを自分で C++ で書いています。288×64 + 64×10 の掛け算と足し算を、int8 でひたすら計算するだけ。3章で「手書きのCもアリ」と書いたのは、まさにこれです。

// 考え方のイメージ（実際のコードは firmware/mnist_inference.cpp）
for (int j = 0; j < 64; j++) {          // 隠れ層の64個それぞれについて
  int32_t sum = bias1[j];
  for (int i = 0; i < 288; i++) {       // 288マスぶん
    sum += input[i] * w1[j][i];          // int8 × int8 を int32 に足していく
  }
  hidden[j] = relu(requantize(sum));     // 0未満は0にして、int8 に戻す
}
// 出力層も同じように計算して、いちばん大きい番号が答え
項目値
モデル288 → 64 → 10 の全結合（ReLU）
重みの大きさ（int8）19,072 バイト（約19KB）
正解率（float32）97.33%
正解率（int8）97.34%

MNIST（手書き数字の定番データ）のテスト画像1万枚を 16×18 に縮めて評価。実際のタッチパネルで書いた字での正解率は、これから確かめる予定です。

注目してほしいのは、int8 にしても正解率がまったく落ちていないこと（むしろ0.01%だけ上がっています）。3章の「量子化しても、AIは意外なほど平気」を、数字で確かめられる実例です。

ちょっと寄り道：データの「形」が合わないと……

この作品では、線を1ピクセルの細さにした版も試しています。ところが、太い線で学習したモデルに、細い線を太らせなおしたデータを見せたら、正解率は約42%まで下がってしまいました。人間には同じ数字に見えても、AIにとっては「見たことのない形」だったんですね。学習と本番で、データの形をそろえる。エッジAIでいちばんよくつまずくポイントです。

micro:bit でほかに作ったもの

  • micro耳it：家電の「ピー」という音を micro:bit が聞きつけて、無線で知らせてくれる作品。たのしいmicro:bitコンテスト2023のエントリー作品です（micromimit）。音を聞き分けるところをAIにしたら……と想像がふくらみます。
  • microgatagot：micro:bit でプラレールを自動運転（microgatagot）。
  • 月齢ドーナツ、bit_chan：サーボで動くかわいい作品たち（moon_donuts、bit_chan）。
やってみよう

micro:bit V2 と micro:bit CreateAI で、「振る」「傾ける」「じっとしている」の3つを見分けるAIを作ってみましょう。できたら、判定結果に合わせてLEDに顔を出す。10分で「自分で作ったAI」が完成します。
