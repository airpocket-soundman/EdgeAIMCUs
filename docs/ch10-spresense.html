第10章

Sony Spresense（CXD5602）

コアが6つもある、ちょっと変わり者の高性能マイコン。ソニー純正のAIツールと組み合わせると、マウス操作だけでAIが作れます。

ボード紹介

Spresense（スプレッセンス）は、ソニーが作ったマイコンボードです。心臓部の CXD5602 は、もともと GPS 付きの腕時計のような「省エネで、でもしっかり計算したい機器」のために作られたチップ。そのせいか、ほかのマイコンにはない個性がいっぱい詰まっています。

チップSony CXD5602
コアArm Cortex-M4F（浮動小数点ユニット付き）×6、156MHz
SRAM1.5MB
Flash8MB（メインボード上）
とくいわざGPS（GNSS）内蔵、ハイレゾ音声の入出力、マルチマイク、専用カメラボード
開発環境Arduino IDE、Spresense SDK（NuttX ベース）
AIの道具Neural Network Console（NNC）＋ DNNRT ライブラリ、TensorFlow Lite for Microcontrollers

コアが6つあると、なにがうれしい？

1つのコアでセンサーを読み続けながら、別のコアでAIの計算をする、といった分業ができます。音や振動のように「データが途切れなく流れてくる」ものをAIで見張るのに向いています。

Neural Network Console でAIをつくる

Spresense ならではの楽しさが、ソニーの Neural Network Console（NNC）との組み合わせです。NNC は、ブロックを線でつなぐようにしてニューラルネットワークを組み立て、そのまま学習までできるアプリ。学習したモデルを nnb という形式で書き出して、Spresense の DNNRT ライブラリで読み込めば、もう推論ができてしまいます。

Arduino のスケッチから見ると、推論の部分は驚くほど短くなります。

#include <SDHCI.h>
#include <DNNRT.h>

SDClass SD;
DNNRT dnnrt;

void setup() {
  SD.begin();
  File nnbFile = SD.open("model.nnb");   // NNC で書き出したモデル
  dnnrt.begin(nnbFile);                  // これで準備完了
}

void loop() {
  DNNVariable input(512);                // 入力の箱を用意して
  float *data = input.data();
  // ... data[] にセンサーの値（特徴量）を入れる ...
  dnnrt.inputVariable(input, 0);
  dnnrt.forward();                       // 推論！
  DNNVariable output = dnnrt.outputVariable(0);
  int answer = output.maxIndex();        // いちばん確からしい答え
}

実例1：卵の茹で加減を、割らずに当てる（egg-analyzer）

「この卵、ちゃんと温泉卵になってる？」。割ってみないとわからないことを、AIで当ててみよう、という作品です。

しくみ

  1. 卵をホルダーにセットして、ステッピングモーターで回します。
  2. そのときのモーターの電流を、M5Stack 用の電流計ユニットで測ります。中身の固まり具合によって、回るときの「手ごたえ」が変わるはず、というアイデアです。
  3. 電流を 2.5ミリ秒ごとに 1024回（約2.6秒ぶん）記録します。
  4. 記録した波形を FFT（高速フーリエ変換）で「どんな揺れ方がどれくらい含まれているか」に変換して、512個の数値にします。
  5. この512個を、NNC で学習した小さなニューラルネットワークに入れて、茹で加減を3つのクラスに分けます。

ネットワークは、512個の入力を100個のニューロンで受ける全結合（Affine）層を中心にした、とてもシンプルなもの。画像AIのような複雑なしかけはいりません。3章の「前処理でAIを楽にする」のお手本のような作品です。FFT で揺れ方を取り出してあげたおかげで、AIは「どの揺れが強いか」を見比べるだけで済んでいます。

ここがポイント

このAIが見ているのは、カメラの画像でもマイクの音でもなく、モーターの電流です。「見た目ではわからないけど、何かの数値にはちがいが出ているかも」と考えると、エッジAIのネタはぐっと広がります。

ハードウェアは、Spresense メインボードと拡張ボード、2.2インチの液晶（ILI9341）、A4988 モータードライバ、NEMA17 ステッピングモーター、電流計ユニット、そして3Dプリンタで作ったケースと卵ホルダー。部品表とソースコードはリポジトリで公開しています。

リポジトリ：airpocket-soundman/egg-analyzer

実例2：振動のパターンを見分ける（MPU6886_spresense）

こちらは、加速度センサー（MPU6886）で拾った振動を、その場でAIに分類させる実験です。

  • 約0.33ミリ秒ごと（1秒に約3,000回）に加速度を読みます。
  • 縦方向の加速度がしきい値を超えた瞬間を「イベント」とみなして、そこから少しさかのぼったところ（50サンプル前）から、合計320サンプルを切り出します。
  • 切り出した波形をそのまま NNC で学習したモデルに入れて、DNNRT で推論します。

「ずっと推論し続ける」のではなく、「何か起きたときだけ推論する」。これは、電池で動かす機器でよく使う省エネの工夫です。さかのぼって記録しておくのは、イベントの始まりの部分を取りこぼさないため。小さなしかけですが、精度にしっかり効いてきます。

データ集め用のスケッチ（collect_vibration_data_02）と、推論用のスケッチ（inference_from_vibration_001）が分かれているので、3章の「①データを集める → ⑤推論する」の流れがそのまま追えます。

リポジトリ：airpocket-soundman/MPU6886_spresense
