第9章

ROHM Solist-AI（ML63Q2557）

SRAM はたったの16KB。なのにAIが動いて、しかもその場で学習までできる。小さな巨人のお話です。

ボード紹介

Solist-AI（ソリストAI）は、日本の半導体メーカー ROHM（ローム）が作った、AI用のアクセラレータを内蔵したマイコンのシリーズです。この章で使う ML63Q2557 には、AxlCORE-ODL というAI回路が載っています。評価ボードは DT-EBML63Q2557。

チップROHM ML63Q2557
コアArm Cortex-M0+、48MHz
SRAM16KB
Flash256KB
AIの助っ人AxlCORE-ODL（bfloat16 で計算する、推論と学習のためのアクセラレータ）
AIの道具ROHM の Solist-AI ライブラリ、PC用シミュレータ「Solist-AI Sim」

「その場で学習」ができるマイコン

3章で「学習はパソコン、推論はマイコン」と説明しました。ところが Solist-AI は、マイコンの上で学習までできてしまうのが売りです。これを オンデバイス学習（ODL：On-Device Learning）と呼びます。

そのしくみは、ELM（Extreme Learning Machine）という、ちょっと変わったニューラルネットワークです。

ふつうのニューラルネットワークは、全部の重みを少しずつ何千回も調整して学習します。ELM は、前半の重み（α）をサイコロを振って決めたら、もう動かさない。後半の重み（β）だけを、一発の計算で決めてしまいます。学習がとても軽いので、小さなマイコンの上でもできる、というわけです。

おまけに、α は「サイコロの種」さえ決めておけばチップの中で毎回同じものを作り直せるので、メモリに保存しておく必要すらありません。16KB の世界では、これがとても効いてきます。

実例1：アクリル板を楽器にする（acrylic_pan）

400×300mm のアクリル板をたたくと、どこをたたいたかをAIが当てて、場所ごとにちがう音を鳴らす。スチールドラムのような電子楽器です。センサーは、板に貼った加速度センサー（KX134）たった1つだけ。

しくみ

  1. 加速度センサーを 1秒に25,600回 読み続け、たたいた瞬間を見つけたら 512サンプル（20ミリ秒ぶん）を切り出す。
  2. たたいた瞬間の位置をそろえ、ローパスフィルタ、間引き、窓関数をかけてから FFT。
  3. 周波数の成分を 128個にまとめて、Solist-AI の ELM（入力128 → 隠れ32 → 出力12）に入れる。
  4. 板を 4×3 の 12エリアに分けて、どのエリアをたたいたかを当てる。

同じ板でも、たたく場所によって振動の「響き方」が変わる。IchiPing（8章）が部屋の響きを聞いていたのと同じ発想を、今度は板でやっているんですね。

項目結果
12エリアの判定（最新モデル、評価用データ 1,426回）89.1%（以前のモデルは67.1%）
60地点の判定（Solist-AI 上のモデル）1位正解率 97.3%、位置の平均誤差 5.55mm

データを 11回に分けて合計 7,132回たたいて集めたことで、12エリアの正解率が 67% から 89% まで上がりました。ここでも効いたのはデータの量と多様さです。

リポジトリ：airpocket-soundman/acrylic_pan

実例2：IchiPing を 16KB に押し込む（IchiPing_solist_AI）

8章の IchiPing（音で窓の開け閉めを当てる）を、Solist-AI に引っ越しさせたプロジェクトです。

もとの IchiPing は、MCX N947 の NPU で約10万パラメータの CNN を動かしていました。これを SRAM 16KB のマイコンにそのまま入れるのは無理。そこで、

  • 音の特徴を、400〜3000Hz の範囲に絞った 167個の数値に小さくする
  • モデルを CNN から ELM（入力167 → 隠れ32）に置きかえる
  • スピーカーとマイクの係は、相棒の M5Stamp S3A（ESP32-S3）にまかせる

という作戦をとりました。学習するパラメータの数は、もとの CNN の約51分の1。AIが使うメモリは約11KB で、16KB の中にちゃんと収まります。

設定1回ごとの正解率多数決での正解率
14グループ（工場出荷のまま、現地での学習なし）99.4%100%
32状態（現地で各状態10回ぶんを追加して学習）99.1%100%

ROHM 公式の Solist-AI Sim（SLV1.00.04）での評価。

ちょっと寄り道：本当は「その場で学習」したかった

実はこのプロジェクト、最初はチップの上での学習（ODL）を使うつもりでした。ところが試してみると学習が安定しなかったため、β の学習だけはパソコンでまとめて計算して、チップに書き込む方式に切りかえています。ELM は β の計算が軽いので、「どこで学習するか」を後から選び直せるのも強みです。うまくいかないときは、作戦を変えればいい。これもエッジAIの楽しみ方です。

リポジトリ：airpocket-soundman/IchiPing_solist_AI
