第13章

RP2040 / RP2350（Raspberry Pi Pico）

数百円で買える、Raspberry Pi 財団のマイコン。すなおな性格で、AIの中身を学ぶ相棒にぴったりです。

ボード紹介

Raspberry Pi といえば Linux が動く小さなコンピュータが有名ですが、同じ Raspberry Pi 財団は、自前のマイコンも作っています。それが RP2040 と、その後継の RP2350。これらを載せたボードが Raspberry Pi Pico と Pico 2 です。

RP2040（Pico）RP2350（Pico 2）
コアCortex-M0+ ×2、133MHzCortex-M33 ×2、150MHz（RISC-V コア Hazard3 ×2 に切りかえ可）
SRAM264KB520KB
Flashボード上に 2MBボード上に 4MB
とくいわざPIO（自由にプログラムできる入出力回路）、安さ、情報の多さ
開発環境Pico SDK（C/C++）、Arduino、MicroPython、CircuitPython
AIの道具TensorFlow Lite for Microcontrollers、Edge Impulse、手書きのC

RP2040 と RP2350 のちがいは「AIの力」

RP2040 の Cortex-M0+ は、とても小さくて省エネなコアですが、積和演算をまとめてこなす命令を持っていません。一方、RP2350 の Cortex-M33 は DSP命令と浮動小数点ユニットを持っています。4章のグループでいうと、RP2040 は「A：すなおなCPUタイプ」、RP2350 は「B：DSP命令でがんばるタイプ」。AIで遊ぶなら、RP2350 がおすすめです。

PIO はセンサー集めの名人

PIO は、ピンの ON/OFF を超正確なタイミングで操る小さな専用プロセッサです。ほかのマイコンでは専用の回路が必要な、I2S のマイクやちょっと変わったセンサーでも、PIO なら自分で「つなぎ方」をプログラムできます。AIに食べさせるデータを集める係として、とても頼りになります。

RP2350 で画像生成AI？

7章で紹介した、顔の画像を作る小さなAI pico-faces。実はもともと、Raspberry Pi Pico 2（RP2350）で動かすために作られたものです。名前の「pico」はここから来ています。

同じ設定（4ステップ、ガイダンスあり）で1枚作る時間を比べると、こんな感じです。

マイコン1枚あたりの時間
RP2350（300MHz）約 10 秒
ESP32-S3（ベクトル命令あり）約 6.9 秒
ESP32-P4（PIE 命令あり、360MHz）約 2.0 秒

RP2350 の値は上流の pico-faces の公表値（オーバークロックして300MHz動作）。ESP32 の2つは pico-faces-tab5 での実測値。

数百円のマイコンが、10秒で顔の絵を1枚描く。速さでは ESP32-P4 にかないませんが、「この値段のチップでここまでできる」という驚きは RP2350 がいちばんかもしれません。

RP2040 で作ったもの

  • Raspberry-Pi-Pico-Hapstack-Bridge：パソコンからは USB スピーカーに見えて、受け取った音を I2S で HapStak（振動で音を感じるデバイス）に送る「橋渡し」ファームウェア。TinyUSB と PIO を使っています（Raspberry-Pi-Pico-Hapstack-Bridge）。音声を途切れなく受け渡す技術は、そのまま音のAIのデータ集めに使えます。
やってみよう

Pico 2 を持っていたら、上流の pico-faces を書き込んで、顔が浮かび上がってくるまでの10秒をじっくり眺めてみてください。ノイズから少しずつ顔が現れるようすは、画像生成AIのしくみそのものです。
