第4章

エッジAIを動かせるマイコンたち

マイコンにも得意・不得意があります。第2部で活躍するマイコンたちを、ここで一気に紹介しちゃいましょう。

AI向きのマイコンを見分ける4つのポイント

2章と3章の話をまとめると、AIが得意なマイコンかどうかは、だいたい次の4つで見分けられます。

🧮

① 計算の力

クロック周波数と、積和演算をまとめてこなせる命令（DSP・ベクトル命令）があるか。

🗄️

② メモリの広さ

SRAM（作業机）がどれだけあるか。PSRAM を足せるか。画像を扱うならここが一番効きます。

🚀

③ AI専用の回路

NPU などのアクセラレータを積んでいるか。あれば桁違いに速くなることも。

🧰

④ 道具のそろい方

メーカーがAI用のライブラリや変換ツールを用意しているか。初心者にはここがとても大事。

ここに、⑤ センサーのつなぎやすさを足してもいいでしょう。マイクやカメラがはじめから載っているボードなら、配線に悩まずにすぐAIを試せます。

マイコンを4つのグループに分けてみる

AIとの付き合い方で分けると、マイコンはざっくり次の4グループになります。

グループA：すなおなCPUタイプ

AI専用の機能は持たないけれど、CPUの力で小さなAIを動かせるマイコン。RP2040（Raspberry Pi Pico）、nRF52833（micro:bit V2）、ESP32（初代）など。センサーの値の分類や、手書き数字の認識くらいなら十分にこなせます。「AIのしくみを手で確かめる」のにぴったりのグループです。

グループB：DSP・ベクトル命令でがんばるタイプ

積和演算をまとめて計算できる命令を持ったマイコン。ESP32-S3、ESP32-P4、Cortex-M33 の RP2350・STM32U585、Cortex-M4F が6つもある Spresense（CXD5602）など。音のキーワード検出や、小さな画像の人物検出が視野に入ってきます。いまエッジAIで遊ぶなら、いちばん層の厚いゾーンです。

グループC：NPU・AIアクセラレータ内蔵タイプ

AIの計算専用の回路を持ったマイコン。NXP の MCX N947（eIQ Neutron NPU）、ROHM の Solist-AI（ML63Q2557）、Sipeed の K210（KPU）など。同じ電力でぐっと速く計算できたり、マイコンの上で学習までできてしまったりと、それぞれ個性が強いのが特徴です。

グループD：マイコン＋Linux の二刀流タイプ

厳密にはマイコンだけではありませんが、最近はマイコンと Linux が動くプロセッサを1枚に載せたボードも出てきました。Arduino UNO Q（STM32U585 ＋ Qualcomm QRB2210）がその代表。重いAIは Linux 側、センサーの読み取りやモーター制御はマイコン側、と役割分担できます。

ちょっと寄り道

表の中で、ML63Q2557 の SRAM が 16KB しかないのに気づきましたか？ ほかのマイコンの30分の1ほどです。それでも、AI専用の回路と工夫しだいで、音や振動の分類がちゃんとできてしまいます。「メモリが大きい＝えらい」ではないのが、エッジAIのおもしろいところ。8章でその工夫をのぞいてみましょう。

どれから始める？ 目的別おすすめ

やってみたいことおすすめ理由
とにかく安く、手軽に始めたいESP32-S3 のボード（AtomS3 など）数千円で買えて、情報も道具も多い
子どもと一緒に、ブロックやPythonでmicro:bit V2マイクと加速度センサーが最初から載っている
カメラで人やものを見分けたいESP32-S3（カメラ付き）、ESP32-P4、MCX N947PSRAMやNPUがあると画像が扱いやすい
大きめのモデルで遊びたいESP32-P4（Tab5）PSRAM 32MB と大きな画面で、画像生成まで試せる
AI専用チップのすごさを体感したいFRDM-MCXN947、Solist-AINPU・アクセラレータを使うと世界が変わる
センサー処理と重いAIを両方やりたいArduino UNO Qマイコンと Linux の役割分担ができる

マイコンのその先：AI SoC

最後に、この本の「すぐ外側」にいる仲間も紹介しておきます。M5Stack の Module LLM などに載っている Axera の AX630C のようなチップは、Linux が動くプロセッサに強力なNPUを組み合わせたAI SoCです。マイコンよりひとまわり大きな世界ですが、小さな言語モデル（LLM）や本格的な物体検出まで手のひらサイズで動きます。

マイコンのボードとUARTでつないで「重い仕事はAI SoC、センサーと画面はマイコン」という組み合わせ方もできます。マイコンでエッジAIに慣れたら、次のステップとしてのぞいてみるのも楽しいですよ。

やってみよう

3章の「やってみよう」で決めた作りたいものに、どのグループのマイコンが合いそうか考えてみましょう。音や振動ならグループA・Bでも十分。カメラならB・C。迷ったら、まずは手元にあるボードで始めるのが一番の近道です。
