第13章

まだまだいる！ほかのマイコンたち

第2部の最後は、作者の作品に登場した個性ゆたかなマイコンたちを、駆け足で紹介します。

Kendryte K210（Sipeed Maix Bit、M5StickV）

コアRISC-V 64bit ×2、400MHz
SRAM8MB（うち 2MB は AI 用）
AIの助っ人KPU（畳み込みニューラルネットワーク専用のアクセラレータ）、マイクアレイ用の音声処理回路
開発環境MaixPy（MicroPython）、Kendryte SDK

K210 は、「マイコンでカメラAI」がまだ珍しかったころに登場して、多くのメイカーを驚かせたチップです。SRAM が 8MB もあり、KPU で顔検出や物体検出がサクサク動きました。

作者は、K210 のマイクアレイ用の回路に注目しました。6＋1個のマイクを並べたボードをつなぐと、音がどの方向から来ているかをチップが計算してくれます。これを使って作ったのが、

  • SoundVisualizer：カメラの映像に「音の出どころ」を色で重ねて表示する、持ち運べるサウンドカメラ（SoundVisualizer）。
  • SoundCamera：同じしくみで、パソコン用のサウンドカメラにしたもの（SoundCamera）。

どちらもニューラルネットワークは使っていませんが、「音の方向がわかる」ことは、音のAIの前処理としてとても強力です。「どこから鳴ったか」と「何の音か」を組み合わせたら……と想像すると、ワクワクしてきませんか？

M5StickV（K210 搭載）は、サーボで文字を表示する mechanical_display（mechanical_display）の司令塔としても活躍しました。

ESP32（初代）：M5Stack の定番

5章の ESP32-S3 の先輩です。M5Stack Core / Core2、M5StickC Plus、ATOM Matrix など、たくさんのボードに載っていて、作者の作品にも一番たくさん登場します。

  • Xtensa LX6 ×2、240MHz、SRAM 520KB
  • S3 のようなAI向けのベクトル命令はないものの、小さな分類モデルなら十分に動きます
  • UIFlow（ブロック）でも作れるので、ワークショップにも便利（M5ColorFinderWS）

作品の例：スマートスケール（M5StackSmartScale）、ストロボスコープの表示側（Stroboscope）、スタックチャンの練習（stackchan_try）、ATOM Matrix のクリスマスツリー（AtomMatrixTree）、FPVカー（RoverC_FPVCar）など。センサーの値を集めてパソコンやサーバーに送る役としても、仕事の現場で活躍しています。

Renesas RA4M1（Arduino UNO R4）

  • Cortex-M4F、48MHz、SRAM 32KB、Flash 256KB
  • Arduino UNO の第4世代。おなじみの形のまま、中身が 32ビットの Cortex-M4 になりました

作者はストロボスコープで、フラッシュを光らせるタイミングの係に使っています（M5Stack_Stroboscope）。SRAM 32KB は AIにはちょっと小さめですが、DSP命令を持つ Cortex-M4F なので、加速度の簡単な分類くらいなら挑戦できます。

マイコンのその先：Axera AX630C（M5Stack Module LLM）

4章の最後で紹介した AI SoC の代表です。M5Stack の Module LLM に載っていて、小さな言語モデル（LLM）や音声認識、物体検出を手のひらサイズで動かせます。

作者は、M5StickC Plus2 などの ESP32 ボードから UART で Module LLM に話しかける実験をしています（M5Stack_LLM）。マイコンが「窓口」、AI SoC が「頭脳」という組み合わせは、マイコン単体では届かない大きなAIを、マイコンの作品に取り入れる近道です。

Raspberry Pi（Linux のシングルボードコンピュータ）

マイコンではありませんが、ひとつ上のクラスのエッジAIとして、Raspberry Pi も作者の作品にたくさん登場します。古い8mmフィルムカメラをデジタル化する一連の作品（yashica8、retrofit-8mm-movie-camera-V2 ほか）では、Raspberry Pi Zero 2 W がカメラの心臓部です。

Raspberry Pi Zero 2 W でも、YOLOX のような物体検出モデルを動かせます。「マイコンでは足りないけど、GPU までは要らない」。そんなときの頼れる選択肢です。
