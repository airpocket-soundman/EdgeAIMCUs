第2章

マイコン（MCU）ってなに？

指先ほどのチップに、コンピュータがまるごと1台。まずは主役の自己紹介から始めましょう。

チップ1個でコンピュータ1台

マイコンは「マイクロコントローラ（Microcontroller Unit）」の略で、英語では MCU と書きます。

パソコンの中を開けると、CPU、メモリ、ストレージ（SSD）、いろいろな接続端子が、それぞれ別の部品として並んでいます。マイコンは、それをぜんぶ1つのチップに詰め込んだものです。

電子レンジ、炊飯器、エアコンのリモコン、車、おもちゃ。家の中を見渡すと、マイコンは数十個は隠れているはず。世界でいちばんたくさん使われているコンピュータ、それがマイコンです。

パソコンや Raspberry Pi とくらべてみよう

ざっくり比べると、マイコンの「小ささ」がよくわかります。

メモリは Raspberry Pi の約1万分の1。数字だけ見ると心細いですね。でも逆に言えば、電池で何日も動いて、電源を入れた瞬間から仕事を始められて、1個数百円。この身軽さがマイコンの最大の武器です。

ヒント

単位の感覚をつかんでおきましょう。1MB（メガバイト）＝1024KB（キロバイト）、1KB＝1024バイトです。スマホで撮った写真1枚が数MBなので、マイコンの作業用メモリには、写真1枚すら丸ごとは入らないことが多いんです。

2種類のメモリ：Flash と SRAM

マイコンでAIを動かすとき、いちばん気にするのがメモリです。マイコンには性格のちがう2種類のメモリがあります。

  • Flash（フラッシュ）：電源を切っても消えない「本棚」。プログラムや、AIが学習で覚えた数値（重み）を置いておきます。容量は数百KB〜数MB。
  • SRAM（エスラム）：電源を切ると消える「作業机」。計算の途中経過や、マイクやカメラから入ってきたデータを広げておく場所です。容量は数十KB〜数MBで、Flash より小さいのがふつう。

AIの計算は、本棚（Flash）から重みを読みつつ、机（SRAM）の上で途中の結果を広げながら進みます。机が狭いと、大きな計算は広げきれない。マイコンでAIを動かすときの工夫の多くは、この机をどう上手に使うか、という話になります。

最近は、チップの外に PSRAM という大きめのメモリ（数MB〜32MB）を追加できるマイコンも増えました。机の横に補助テーブルを置くイメージです。ちょっと遠いので速さは落ちますが、画像を扱うときにはとても頼りになります。

外の世界とつながる「周辺機能」

マイコンの本領は、センサーやモーターといった外の世界とじかにつながれることです。そのための機能を周辺機能（ペリフェラル）と呼びます。エッジAIでよく使うものを紹介しましょう。

名前なにをする？エッジAIでの出番
GPIOピンをON/OFFする、ON/OFFを読むLEDで結果を表示、ボタンで録音開始
ADC電圧を数値に変えるアナログマイク、振動センサー
I2C / SPIセンサーと数本の線で会話する加速度センサー、距離センサー、画面
I2S / PDM / SAI音声データを途切れなく受け取るデジタルマイク（キーワード検出、音の分類）

DMACPUを使わずにデータを運ぶ音や画像を受け取りながら、同時にAIを計算
タイマー / PWM正確な時間を刻む、モーターを回す一定間隔でセンサーを読む、結果でロボットを動かす

マイコンの「頭脳」いろいろ

マイコンのCPU部分はコアと呼ばれ、いくつかの流派があります。

  • Arm Cortex-M シリーズ：いちばんの大所帯。STM32、NXP の MCX、Raspberry Pi の RP2040 / RP2350 などが採用しています。
    • Cortex-M0+：小さくて省エネ。AIには少し非力。
    • Cortex-M4 / M33：DSP命令（信号処理向けの便利な命令）を持ち、AIの入門にちょうどいい。
    • Cortex-M7：速さ重視のパワー型。
    • Cortex-M55 / M85：Helium というベクトル命令を持つ、AI時代のコア。
  • Xtensa：Espressif の ESP32 / ESP32-S3 が採用。ESP32-S3 はAI向けのベクトル命令を追加しています。
  • RISC-V：自由に使えるオープンな命令セット。ESP32-C3 / C6 / P4、RP2350（切り替え式）、Sipeed の K210 などが採用。
ちょっと寄り道

AIの計算の9割以上は「かけ算して、足す」の繰り返しです。これを 積和演算（MAC：Multiply-Accumulate） と呼びます。DSP命令やベクトル命令は、この積和演算を1回の命令で2個、4個、16個……とまとめて計算できるしかけ。だから同じクロック周波数でも、こうした命令があるかないかでAIの速さが何倍も変わります。

そして、NPU を積んだマイコンの登場

ここ数年で、マイコンの世界に新しい仲間が加わりました。NPU（Neural Processing Unit）、つまりAIの計算専用の回路を内蔵したマイコンです。

たとえば NXP の MCX N947 には「eIQ Neutron NPU」が載っていて、CPUだけで計算するより何十倍も速く画像認識ができる、とうたわれています。マイコンの世界でも「AI専用エンジン」が当たり前になりつつあるんですね。どんなマイコンがあるのかは、4章でじっくり見ていきます。

やってみよう

手元にマイコンボードがあれば、使われているチップの型番を調べて、メーカーのデータシートで「CPUコアの種類」「Flash と SRAM の容量」を探してみましょう。この3つがわかれば、そのマイコンでどれくらいのAIが動きそうか、だいたい見当がつくようになります（見当のつけ方は3章で）。
